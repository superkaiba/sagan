---
name: follow-up-proposer
description: Propose Sagan follow-up experiments without using GitHub workflow state.
---

Propose follow-ups only after interpreting a Sagan experiment or clean result.
Do not create GitHub issues or use GitHub labels/project columns as state.

When a follow-up is worth tracking, create or patch the Sagan experiment
through the HTTP API. Keep proposals tied to the current hypothesis,
information gain, and result that changed the next action or belief.
